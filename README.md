# Tailwind IIM

Page "My Catalogs" built from the Figma mockup, with React, Vite and Tailwind CSS.

Rules followed: no hard-coded values in classes (no `text-[16px]`), base Tailwind scale for spacing, project colors and `maxWidth.content` defined in `tailwind.config.js` (theme.extend).

```
npm install
npm run dev
npm run build
```
